# Customer Churn Prediction

## 📌 Project Overview

Customer churn is a major challenge for telecommunication companies. Identifying customers who are likely to leave can help businesses take proactive retention actions.

This project develops a **Customer Churn Prediction system** using the 
**<a href="https://www.kaggle.com/datasets/blastchar/telco-customer-churn", target="_blank">IBM Telco Customer Churn dataset** and **Logistic Regression**.

Dataset Likn: <a h>

The project follows a complete Machine Learning Life Cycle, starting from data understanding and exploratory data analysis (EDA) to model training, hyperparameter tuning, model interpretation, and model saving.

---

## 🎯 Project Objective

The main objective of this project is to:

- Analyze customer behavior and service information.
- Identify patterns associated with customer churn.
- Build a binary classification model to predict customer churn.
- Evaluate the model using multiple classification metrics.
- Improve Logistic Regression using hyperparameter tuning.
- Compare different regularization techniques.
- Interpret the model using feature coefficients.
- Save the final trained model for future deployment.
